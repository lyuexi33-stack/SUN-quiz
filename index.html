① 题库模板

xlsx 需包含 6 列：题干、选项A、选项B、选项C、选项D、答案。
单选答案填一个字母（如 A），多选填多个字母（如 ABD）。

④ 更新线上题库

1. 打开 GitHub 仓库 → 进入 data 文件夹 → Add file → Upload files；
2. 把下载的 unitX.json 拖进去覆盖同名文件；
3. Commit changes，约 1~2 分钟后网站自动生效。
